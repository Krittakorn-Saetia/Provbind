## The live-mode bug (#12)

`synth.library()` timed every event from `2026-09-28T10:00:00Z`. The live-mode test feeds those events to `node.run` with `--grace 3600`, and live mode measures the grace period on the wall clock. So from an hour after that date, every held event was already past its grace period: each became `binding / unknown_container`, the detection counts were wrong, and the test failed. PH4-17 runs `node/tests`, so it failed too.

`library(attack2_files, start="2026-09-28T10:00:00Z")` keeps the old default, so every replay test and its expected counts are unchanged. Only the live test passes `datetime.now(timezone.utc)`.

## The six new tests (#14)

Each follows CF-05's pattern: real input from environment variables gives pass or fail; without it, the test measures the node on synthetic data and records **not_run** with the numbers.

| ID | File | Real input on the demo PC |
|---|---|---|
| PH2-10 | `tests/capability/test_ph2_10_cold_start.py` | `PROVBIND_NODE_SUMMARY`: a `node.run --summary` file from a run that deployed a pod. Pass: a window for each container, 0 held events lost |
| MLA-07 | `tests/capability/test_mla_07_dcap_per_method.py` | `PROVBIND_RECORDING` (with `cap.yaml` applied) and `PROVBIND_MLA07_ENVELOPES="<ML-A envelope>,<allowlist envelope>"`, plus the run folder's `bindings.json` and `ground_truth.csv`. It reports D_cap per benign scenario, per method |
| OH-01 | `tests/capability/test_oh_node_cost.py` | `PROVBIND_RECORDING` with at least 100,000 events. p50 and p99 per-event latency |
| OH-02 | same file | `PROVBIND_RECORDING`, plus `PROVBIND_TETRAGON_CPU_S` and `PROVBIND_TETRAGON_RSS_KB` measured for Tetragon alone under the same load. The node's CPU and peak memory come from `os.wait4` on a `node.run --replay` child |
| OH-03 | same file | `PROVBIND_OH03_STORM`: a recording of the 10,000-process exec storm (`PROVBIND_OH03_EXPECTED` if not 10,000) |
| OH-06 (P2) | same file | `PROVBIND_OH06_SUMMARIES="<1>,<10>,<50>"`: three `node.run --summary` files from the scale test (PH4-04) |

- MLA-07: 0 D_cap for both envelopes (the synthetic benign rows have no capability events).
- OH-01: 6,518 events, p50 5.0 µs, p99 17.5 µs.
