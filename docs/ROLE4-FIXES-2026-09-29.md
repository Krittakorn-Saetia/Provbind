**`controller/watch.py`**

- **Fails closed.** Any verification failure, including cosign missing, gives `verified: false`. It used to return `True`.
- **Verification uses Role 2's `compiler.evidence`,** which also requires an image signature for the digest. cosign v3's `verify` alone passes an attested but unsigned image.
- **Verifies the running digest** from the container status's `imageID`, never the tag (PH2-08).
- **Stores Γ_I** in `contexts/<hex>.json` (PH2-09): the key id, the three checks, builder, commit, Rekor log index, the signature bundle with its inclusion proof, and t0.
- **Takes `mounts`, `run_as_root` and `privileged` from the pod spec.** Container settings first, then the pod's; the volume mounts are added to the files Kubernetes manages.
- **Sets `envelope_ready` only when the file exists,** and compiles once per verified digest.
- **Removes bindings of deleted pods,** and a restarted container's old IDs (Role 3's Q5).
- **No silent mock mode.** Without the Kubernetes client or a cluster it exits 3 instead of writing a fake binding.
- **`--image REF@DIGEST`** binds one image without a cluster, for local checks and tests. `--once` binds the pods that exist and exits.

**`alerts/run.py`**

- **Once per detection.** Detections already in the log are skipped. Rerunning `--once` used to alert everything again, with the same IDs.
- **Complete lines only.** A half-written detection line waits for its newline instead of being dropped.
- **Attribution looks up the file the clause names.** For D_write that's `/etc/passwd`, not the writer `/tmp/.x9`.
- **Signing identity comes from the envelope,** or `null`. It used to invent `sf9-26/local-build` and Rekor index `123456789`.
- **κ comes from the binding.** ρ comes from `context.declared`, package and depth.
- **Chains** are keyed by container. The chain's pids are the detections' own pids, not their parent's, so the app's other children don't join an attack chain. Times are the events' own `time`s, 60 s window. Chain IDs come from the first detection, so they are stable across restarts.
- **`violated_clause`** reads `kind: path: detail`.

**`alerts/log.py` and `alerts/verify_log.py`**

- **One locked writer** for the log and `alerts.jsonl`, so `alerts.run` and `alerts.trust` can both append without breaking the chain.
- **The logged record is exactly the alert.** It used to be hashed with `log_k: 0`.
- **`alert_id` is `alr-<k>`,** so IDs are unique across writers and restarts.
- **`verify_log`:**
  - takes `--run`, as §3.3 says. With the old positional form, `--run DIR` checked a folder named "--run" and said OK;
  - checks each record's `k` too. Role 1's `tamper.sh` flips the first lowercase letter of a line, which is the `k` key, and a hash-only check misses that;
  - reports a line that is no longer JSON at its record, instead of crashing;
  - treats a missing log as exit 2, not a pass;
  - offers `verify(run)` returning `.ok` and `.first_bad`, for Role 1's E2E-12, which now passes.

**`alerts/attribute.py`**

- **Actually loads each new envelope into Neo4j** (the §8 Cypher, batched). Before, the graph was never filled.
- **Falls back to the envelope's `files[path].layer`** when Neo4j is off or missing (`PROVBIND_NEO4J=off` forces it).

**`alerts/trust.py`: new, the Phase 6 trust loop**

- **Four checks:**
  - key: `keystatus.json`;
  - trans: the stored Rekor inclusion proof, re-hashed to its root, plus the checkpoint;
  - builder: `builder_denylist.json`;
  - comp: OSV advisories in `advisories/*.json`, where `MAL-` IDs withdraw trust and a CVE is only reported.
- **Alerts once, on the 1 → 0 flip,** and saves state in `trust/<hex>.json`.
- **Reacts within 2 s of an input changing,** so trust-1's 30 s window works; otherwise it runs every ΔR = 300 s.
- **Helpers:** `python -m alerts.trust key-id` prints a key id, and `set-key --state revoked` marks a key revoked (scenario trust-2).

**`alerts/show.py`:** one line per alert, coloured by bucket, with clause, attribution and signing identity. Trust alerts show the failed checks. `--follow` keeps printing.

**`contracts/check_contracts.py`:**
